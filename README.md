# ⚔️ Elden Ring Landing Page

A responsive landing page inspired by **Elden Ring**, created as a front-end practice project using only HTML and CSS.

The design features a modern game-themed interface with multiple sections, immersive visuals, and a responsive layout that works across different screen sizes.

## ✨ Features

* 🎮 Elden Ring-inspired design
* 📱 Fully responsive layout
* 🎨 Clean and organized HTML & CSS
* 🖼️ High-quality game images and assets
* 📋 Multiple landing page sections:

  * Hero
  * Services
  * Portfolio
  * About
  * Pricing
  * Contact
* ⭐ Font Awesome icons
* 🌐 Google Fonts integration

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/elden-ring-landing-page.git
```

Go to the project folder:

```bash
cd elden-ring-landing-page
```

Open **index.html** in your browser.

Or run a local server:

```bash
python -m http.server
```

Then visit:

```text
http://localhost:8000
```
